> **版本**: v1.0.0
> **目标平台**: 嘉楠 K230 (CanMV / MicroPython)
> **架构模式**: AppManager + BaseApp
> **规划日期**: 2026-05-03
> **项目根目录**: `D:\OneDrive\01.project\50.K230_Universal_Detection_Basic\多功能AI视觉检测`

## 1. 设计目标

将两个独立的功能脚本：

- `归档/taping_checker 稳定版.py` — 胶带检测（AI 推理 + OSD UI + GPIO 报警）
- `归档/picture_get_key 精简版.py` — 按键拍照（摄像头采集 + 按键触发 + 图片保存）

整合到 **AppManager + BaseApp** 架构中，实现：

- 桌面图标双应用入口
- 统一生命周期管理（启动/退出动画、资源清理）
- 共享 PipeLine 视频流水线
- 最小化系统裁剪（删除 WiFi/锁屏/翻页/多语言等无用功能）

## 3. 核心设计决策

| 决策项                    | 方案                                                  | 理由                                 |
| ------------------------- | ----------------------------------------------------- | ------------------------------------ |
| **AppManager 来源** | 从 `k230/ybMain/main.py` 提取核心类，大幅精简       | 只保留应用扫描/注册/启动/切换/Dock   |
| **BaseApp**         | 直接复制 `k230/ybMain/base_app.py`                  | 生命周期和动画逻辑完全复用，无需改动 |
| **LVGL 初始化**     | 保留在 `main.py` 中                                 | 两个应用共享同一个显示系统           |
| **PipeLine 共享**   | `AppManager` 创建一次，通过 `app_manager.pl` 引用 | 避免重复初始化摄像头和显示           |
| **Dock 栏**         | 两个应用都放入 Dock                                   | 只有两个应用，Dock 快速切换最方便    |
| **锁屏**            | **删除**                                        | 最小化系统，降低复杂度               |
| **页面翻页**        | **删除**                                        | 两个应用一页足够                     |
| **WiFi/网络**       | **删除**                                        | 两个功能都不需要网络                 |
| **多语言**          | **删除**，硬编码中文                            | 自用项目，简化配置系统               |
| **欢迎页**          | **删除**                                        | 加速启动                             |
| **状态栏**          | **可选保留**（仅 CPU/内存）                     | 方便调试，可简化实现                 |

## 6. App 封装设计

### 6.1 通用 App 模板

```python
# apps/{app_name}/app.py

import lvgl as lv
from base_app import BaseApp
import _thread

class App(BaseApp):
    def __init__(self, app_manager):
        # 加载图标
        try:
            with open(f"/sdcard/apps/{app_dir}/icon.png", 'rb') as f:
                img_data = f.read()
                icon_img = lv.img_dsc_t({
                    'data_size': len(img_data),
                    'data': img_data
                })
        except:
            icon_img = None
      
        super().__init__(app_manager, name="应用名称", icon=icon_img)
      
        self.pl = app_manager.pl
        self.is_running = False
  
    def initialize(self):
        """启动应用时调用 - 创建界面并启动工作线程"""
        # 创建内容区域（标题栏下方）
        self.content = lv.obj(self.screen)
        self.content.set_size(lv.pct(100), 420)
        self.content.align(lv.ALIGN.BOTTOM_MID, 0, 0)
      
        # 启动工作线程
        self.is_running = True
        _thread.start_new_thread(self.worker_loop, ())
  
    def worker_loop(self):
        """应用主循环 - 在子线程中运行"""
        while self.is_running:
            # 业务逻辑
            pass
  
    def deinitialize(self):
        """退出应用时调用 - 停止线程并清理资源"""
        self.is_running = False
        # 释放资源
        import gc
        gc.collect()
```

## 11. 风险与注意事项

| 风险                                   | 影响                   | 缓解措施                                                 |
| -------------------------------------- | ---------------------- | -------------------------------------------------------- |
| **OSD 与 LVGL 触控坐标映射偏差** | 按钮点击不命中         | 统一使用 640x480 坐标系，仔细校准                        |
| **KPU 内存未释放**               | 切换应用后内存不足     | `deinitialize()` 中显式 `del kpu` / `gc.collect()` |
| **子线程未停止**                 | 退出应用后线程仍在运行 | 使用 `self.is_running` 标志 + 超时等待                 |
| **GPIO 状态残留**                | 退出后报警灯常亮       | `deinitialize()` 中调用 `reset_outputs()`            |
| **PipeLine 被重复创建**          | 摄像头冲突             | 确保只在 `main.py` 中创建一次                          |
| **LVGL 对象引用错误**            | 程序崩溃               | 使用 `try/except` 包裹 LVGL 操作                       |
